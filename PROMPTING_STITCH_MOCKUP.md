
Saya ingin membuat mockup UI untuk aplikasi travel bernama "RuslyTravel".
Gunakan design system ini untuk SEMUA mockup berikutnya:

WARNA:
- Navy Primary: #10233F (headings, buttons utama)
- Orange Accent: #F58A2A (CTA, highlight, aktif)
- Orange Soft: #FFF1E4 (background badge, timer)
- Navy Muted: #5D7090 (secondary text)
- Background: #F4F7FB
- White: #FFFFFF (cards, surface)
- Success Green: #1F9D67 | Warning Yellow: #F8B34B | Danger Red: #D94F4F
- Gradient: dari #163966 ke #0B2342 (hero/splash)

TYPOGRAPHY: Font "Plus Jakarta Sans"
- Heading: 18-28px, weight 700-800
- Body: 14-16px, weight 400
- Label/badge: 12px, weight 700

SHAPE: Card radius 28px, Button radius 18px, Input radius 20px, Badge pill 999px
BUTTON PRIMARY: background orange, text putih, bold
BOTTOM NAV: 5 tab (Beranda, Rute, Pesanan, Tiket, Profil), tinggi 74px
PLATFORM: Mobile app (Flutter), ukuran layar 390x844 (iPhone 14)
